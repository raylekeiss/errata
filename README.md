# ERRATA-エラータ-

世界史探究で使用する、古代から近世末期にかけての復習用ゲーム。帝国主義、第一次大戦以降などは表現上の問題から省いている。主人公は新たに採用されたアカシックレコードの図書館司書として、先輩や同僚らと、歴史の誤植を修正していく。

- `index.html` … ゲーム本体
- `img/` … 画像
- `credits.html` / `credits.json` … 肖像の出典一覧
- `tools/get_credits.py` … 出典情報を集め直すスクリプト
- `tools/pick_zuhan.py` / `tools/apply_zuhan.py` … 図版・地図の写真を選ぶ・取り込むスクリプト
- `drill/chusei.html` … 中世の巻 一問一答ドリル（単体で動く試験対策用。252問）

## ミッション

ホーム右上の「ミッション」。報酬（各時代の栞）は受け取りボックスに届く。中身と報酬の数は `index.html` の `MS_DAILY`・`MS_ACH`・`MS_ALL_BONUS` で変えられる。
- デイリー（端末の日付で毎日リセット）：ドリル10問・ドリル5問正解・ストーリー1節・カードゲーム1回、各1枚。ぜんぶ達成でさらに各2枚
- 達成（通算）：ドリル正解数・受験対策の正解数・集めた頁・読み終えた節。段階ごとに各2〜8枚

## ドリルの画面

タブは「試験範囲で選ぶ」「受験対策」「記述対策」「図版・地図」の4つ（記述対策・図版・地図は下の節を参照）。試験範囲のタブは「マイ範囲」＋全15章の棚。マイ範囲では章ごと、さらに王朝・テーマ（問題IDの節。名前は `index.html` の `QSEC`）ごとにチェックを外せる。選んだ範囲は記録の `qmy.secs` に残る。

問題文の `{{…}}` は下線部として表示される（正誤訂正の問題は「下線部を訂正すると？\n（文）」の形。先頭の「下線部を訂正すると？」は四角で囲んで表示）。改行は `\n`。

## ドリルの編集（先生用）

`tools/drill-edit.html` で、ドリル（`"Q"`）と受験対策（`"JQ"`）の問題文・正解・誤答・解説・紙魚の一言を直せる。直した分はその端末のゲームにすぐ反映される（同じブラウザ）。全員に反映するときは「書き出す」でできた `drill-edits_日付.json` を `python3 tools/apply_drill_edits.py drill-edits_日付.json` で本体に取り込む。

- 問題の削除もできる（問題を開いて「この問題を削除」）。取り込むまでは「削除した分」から取り消せる。取り込むとデータから消える
- 解説は2つの欄に分けている。`x`＝硬い解説（全問必須、事実だけ）、`n`＝紙魚の一言（任意。小ネタがあるときだけ）。一言がある問題だけ、解説カードに紙魚の顔と「シミ」の吹き出しが出る
- 受験対策の問題は `"JQ"`（1件1行）。`u`＝単元（名前は `"JU"`）、`lv`＝標準（教科書の太字）／発展（太字以外の本文・注・表）、`ok`＝1採用／-1不採用／0未定。編集画面の ○／× で採否を決める（同じ印をもう一度押すと未定に戻る）
- 受験対策タブ：ドリル画面の「受験対策」。教科書の章ごとの棚＋「マイ範囲」（単元にチェックを入れて保存。通常ドリルの近い章の問題も混ぜられる。対応表は `index.html` の `JMAP`）。「標準だけ／標準＋発展」を切りかえられる
- 出す問題は採用（ok:1）だけ。`"JCFG": {"pending":1}` のあいだは未定（ok:0）も出す。編集画面の「生徒に未定も出す」で切りかえ、書き出し→取り込みで反映
- 受験対策の栞は控えめ（はじめて正解1枚・克服2枚・正解済み0枚）。`index.html` の `qGain` で変えられる
- 受験対策の進み具合は記録の `jq`（単元ごとの文字列：0未回答・1正解・2不正解）。学校アカウントの保存（1件49000文字まで）におさまるよう小さくしてある

## 記述対策（ドリルの「記述」タブ）

ドリル画面の3つ目のタブ。「基本問題」と「実戦問題」を切りかえる。棚は教科書の章ごと（受験対策と同じ）で、先頭の「全範囲から」は基本問題ならまだクリアしていない問題から、実戦問題ならまだ書いていない問題からランダムに選ぶ。

- **基本問題**：STEP 1「設問を読み解く」（4択＋指定語句の並べ替え。並べ替えは長押しして上下にスライド）→ STEP 2「誤植答案を正す」（模範解答に誤植を仕込んだ答案から、おかしい文をタップして直す）。何度でも繰り返せる
- **実戦問題**：基本問題と同じ設問を実際に書く。字数カウンター（8割の目印つき）と指定語句のチェック → 採点の目安で自己採点 → 模範解答（指定語句に下線）
- 栞：基本問題のはじめてのクリアで10枚、2回目以降は2枚。実戦問題は、字数が半分以上・指定語句がそろった状態で自己採点を記録すると、はじめての1回だけ15枚。時代は単元の章で決まる（受験対策と同じ）
- 記録は `S.kj`（問題IDごとに [基本問題のクリア回数, 読み解きの最高点, 実戦問題の最高点(-1は未)]）。書きかけの答案は学校アカウントの容量を使わないよう、端末（localStorage の `errata_kj_drafts`）だけに残す
- データは `"KQ"`（1件1行・216問）。項目の意味は `index.html` の「記述対策」のコメントを参照。主なもの：`u`＝教科書の単元、`q`＝問題文、`lim`＝制限字数、`terms`＝指定語句（年代の古い順。`ord`＝先頭から何語を並べ替え問題に使うか）、`rd`＝読み解きの4択、`ms`＝模範解答（1文ずつ）、`er`＝誤植（`i`の文の`c`を`w`に置き換える／`at`の位置に余計な一文`s`を差し込む）、`rb`＝採点の目安（減点の2項目は自動で付く）
- 誤植答案は `ms` と `er` から自動で作るので、模範解答を直すときは `er` の `c`（正しい語句）がその文に1回だけ含まれるようにする
- 問題文・模範解答・解説はすべてオリジナル。市販の問題集からは扱うテーマ（論点）だけを参考にし、文章は使っていない

## 図版・地図（問題演習の「図版・地図」タブ）

問題演習の4つ目のタブ。白地図・写真を見て答える問題。棚は教科書の章ごと（受験対策と同じ）＋「全範囲から」。出題順・栞は受験対策と同じ（はじめて正解1枚・克服2枚・正解済み0枚）。収録範囲は古代〜近世（教科書の第1〜11章）。

- 形式（`t`）：`map-pick`（地図の4地点から選ぶ）・`map-name`（●の地点の名前）・`map-route`（航路・経路の人物など）・`img-name`（写真1枚→文字の4択）・`img-pick`（文字→写真4枚から選ぶ）。地図から選ぶ・写真から選ぶ問題は、地図上の印・写真をタップしても、ア〜エのボタンでも答えられる
- データは `"ZQ"`（1件1行）。`u`＝教科書の単元、`a`＝正解（地点の名前・写真の枠のキー・語句）、`d`＝ほかの3つ、`view`＝地図の表示範囲、`pt`＝●の地点、`route`＝経路、`img`＝写真の枠、`x`＝解説、`p`＝見るポイント（解説の下に出る）、`n`＝紙魚の一言
- 白地図は `"ZMAP"`（Natural Earth のデータをメルカトルにしたもの。東経−25〜150度が x=0〜2000。アメリカ大陸は x がマイナスの側に描いてある。地点 `pt`・経路 `route`・表示範囲 `view`・河川 `river`・主な湖 `lake`）。経度・緯度から座標へは x = 11.4283×経度 + 285.74、y = 1327.70 − 654.84×ln tan(45°+緯度/2)
- 写真の枠は `"ZI"`（`l`＝名前。答えたあとにだけ出す）。`f`（Commons のファイル名）があれば `img/zuhan/キー.webp` を表示し、右下に作者とライセンスを出す
- 写真の差し替え：`python tools/pick_zuhan.py`（Windows でも可）で候補を集め、pick_zuhan.html で選んで保存 → `python tools/pick_zuhan.py --make zuhan_choice.json` → できた zuhan_out を `python3 tools/apply_zuhan.py zuhan_out` で取り込む（img/zuhan・"ZI"・出典一覧がまとめて更新される）
- 記録は `S.zq`（単元ごとの文字列。受験対策の `jq` と同じ形）
- **テスト中の設定（ローンチ前に戻す）**：`index.html` の `ZH_TEST` が `true` のあいだは、写真がまだない問題も「写真準備中」（枠の名前つき）で出す。`false` にすると写真がそろった問題だけ出る
- 先生用の編集画面（`tools/drill-edit.html`）はまだ図版・地図の問題に対応していない。直すときは `index.html` の `"ZQ"` を直接書きかえる

## 学校アカウント保存版（GAS）

`gas/` の2ファイルをスプレッドシートのApps Scriptに置くと、学校アカウントごとに記録をスプレッドシートへ保存する版になる。ゲーム本体はこのリポジトリの `index.html` を読み込むので、ゲームの更新はGitHub側だけでよい。

## マイルーム（旧：箱庭）

ホームの「マイルーム」で、斜め見下ろし（横2：縦1）の書斎を飾れる。床は16×16マス。2本指（PCはホイール）で拡大・縮小、拡大中は1本指で移動できる。家具を長押しすると、もようがえに入ってそのまま動かせる。
家具・壁紙・床は時代別の栞と交換し、「もようがえ」→「持ち物」から置く・変える。手に入れた頁は額に入れて壁に掛けられる。SDキャラは「キャラ」から表示・非表示を選べ、空いている床をふらふら歩く（タップでひとこと＋差分の切り替え）。

- 家具の一覧はデータ内 `"furniture"`、壁紙と床は `"roomskins"`（どちらも1件1行）。`k`=キー、`e`=時代（0古代・1中世・2近世、-1は最初から持っているもの）、`t`=floor/wall、`g`=分類（本棚・家具・置物・巨大。壁の家具は自動で「壁かけ」）、`w`・`d`=マス数、`h`=高さ、`p`=栞の枚数、`x`=説明（地の文）
- SDキャラの一覧は `index.html` の `SD_LIST`（名前・仮の色・表示できる条件・ひとこと。絵がほかのキャラと逆向きなら `rev:1` で歩くときの向きをそろえる）
- 絵ができたら `IMG` に登録すると、仮の絵の代わりに表示される

| 種類 | IMGのキー | 描く大きさ（ゲーム内の単位。2倍で描くのがおすすめ） |
|---|---|---|
| 床の家具 | `家具_A1` など | 幅 (w+d)×24、高さ (w+d)×12＋h。下の端に床のマスがくるように。向きは1方向だけ（反転はゲーム側） |
| 床の家具（反対向き） | `家具_A1_m` など（任意） | 文字入りなど反転できない家具の反対向きの絵。なければ、データに `"nf":1` を付けると向きを変えられなくなる |
| 壁の家具 | `家具_A8` など | 左の壁に掛けた向きで、幅 w×24、高さ h＋w×12（右の壁では反転） |
| 壁の家具（右の壁用） | `家具_E7_m` など（任意） | 地図など左右反転できない絵の、右の壁向き（右下がり）の絵。あれば右の壁で反転せずに使う |
| SDキャラ | `SD_シミ`、差分は `SD_シミ_2`, `SD_シミ_3`… | 大きさ・縦横比は自由（余白は切って使う）。足元を絵の下端にそろえ、表示の高さは `SD_H`（ゲーム内122）で決まる |
| 主人公のSD | `tools/hero_parts/` にパーツ（素体 `skin1〜3`、前髪 `front_色`、後ろ髪 `back_長さ_色`・素体より手前に来る部分 `side_長さ_色`）を置き、`python3 tools/compose_hero.py` で完成絵を書き出す。キーは `SD_主人公_肌1_黒`（後ろ髪ができたら `SD_主人公_肌1_ボブ_黒`） | パーツはすべて2048px四方の同じキャンバスで。前髪は必ず重なり、後ろ髪の長さは選択式（`LOOK_HAIRS` に足すと選択画面に出る）。完成絵がなければ1つ手前の絵で表示 |
| 壁紙 | `壁紙_W1` など | 模様1回ぶんを、壁の高さいっぱいの長方形で（横につないで貼る。斜めにするのはゲーム側） |
| 壁紙（1枚絵） | データに `"fit":"span"` なら `壁紙_キー`、`"fit":"pair"` なら `壁紙_キー_L`・`壁紙_キー_R` | span：横5.37：縦1の1枚を左右の壁にまたがせる／pair：横2.68：縦1を左右に1枚ずつ（壁の高さは160） |
| 絨毯（平たい置き家具） | `家具_E6` など | 真上から見た平面の絵でよい（斜めにするのはこちら）。高さ6以下の家具は上に家具を置けて、キャラも上を歩ける |
| 床 | `床_F1` など | 正方形（`rep` マス四方に1枚。床一面を1枚で描くなら16。斜めにするのはゲーム側） |

## カードゲーム（旧：図書館探索）

ホームの「カードゲーム」で、手に入れた頁をデッキにして戦うカードモード（Slay the Spire風）。

- 層（難易度）は8段階（`LX_STAGES`）。前の層を完走すると次の層が開く。第1層は一本道6マス、上の層ほど道のりが長く分かれ道が増え（第8層は13列・最大4本）、敵のHP・攻撃の倍率（`hp`・`dmg`）が上がる。完走の栞は第1〜3層が1枚、第4〜6層が2枚、第7〜8層が3枚（時代はランダム）
- 道のりは探索を始めるたびに自動で作る（`lxGenMap`）。マスは 戦闘・エリート・？・宝箱・写本室・休憩・ボス。出やすさは層ごとの `types`
- ？：戦闘・装備・薬・回復のどれか。宝箱：装備か薬。写本室：頁を1枚外すか、HPを6払って頁を強化

- デッキは探索のたびに、持っている人物の頁からランダムに15枚（足りないぶんは基本の頁）。使った頁は捨て札へ行き、山札が尽きたら捨て札をシャッフルして山札に戻す
- 1ターンに1問：そのターン最初に切った人物の頁で、その人物が出てくるドリル問題が出る。正解すると、その頁の効果が1.5倍
- ボスは3ターンごとに「改変の予告」をし、改変バトルの問題（クリアした章から。未クリアなら第1部）で大技を弱められる（全問正解で4割減、人物だけ正解で2割減）
- 戦闘に勝つと、全人物（持っていない頁も含む）からレアリティに関係なく均等に3枚が示され、1枚をその探索のあいだだけ加えられる
- 戦闘中は、状態の札（余白・動揺など）や敵の予告をタップすると説明が出る。手札の頁は1回タップで説明、もう1回で切る。用語の説明文は `LX_TERMS`
- はじめて探索するときは「練習の戦闘」（手札と誤植の行動が固定、シミが1ターン目を案内）に誘う。メニューからいつでも遊べる。案内の文は `lxTutEvent`
- 数値は `index.html` の `LX_BASE`（基本の頁）・`LX_TPL`（人物の頁の型。属性ごと）・`LX_EN`（敵）・`LX_RELIC`（装備）・`LX_POT`（薬）で直せる
- 人物の頁の効果は、属性の型から名前で自動的に1つ選ばれる。レアリティで★2は＋2、★3は＋4、1凸ごとに＋1。★3は2凸で「1枚引く」が付き、4凸でコスト−1

**勉強モード**：メニューの「勉強モード」をオンにすると、ストーリーとマイルーム以外の画面で背景画像・立ち絵・吹き出しを出さない（`html.plain` クラス。記録とは別に `errata_cfg` の `plain` に保存）。隠す対象は CSS の「勉強モード」の節にまとめてある。問題演習の結果の札のシミの顔も、ストーリーのバトル以外では消える（`noteHTML`）。

**テスト中の設定（ローンチ前に戻す）**：`index.html` の `NW_TEST_ALL` が `true` のあいだは、家具・壁紙・床を全種類5つずつ持っている扱いになる（記録には書きこまない）。

- キーワード：保留（ターン終了後も手札に残る）・エーテリアル（引いたターンに切らないと消え、切っても廃棄＝戦闘中に一度だけ）・廃棄
- 敵が強化・妨害してくるターンは、頭上に内容をほのめかすセリフ（`LX_SAY`）。戦闘のあとは、その戦闘で出てきた効果の説明（TIPS）
