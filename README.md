# ERRATA-エラータ-

世界史探究で使用する、古代から近世末期にかけての復習用ゲーム。帝国主義、第一次大戦以降などは表現上の問題から省いている。主人公は新たに採用されたアカシックレコードの図書館司書として、先輩や同僚らと、歴史の誤植を修正していく。

- `index.html` … ゲーム本体
- `img/` … 画像
- `credits.html` / `credits.json` … 肖像の出典一覧
- `tools/get_credits.py` … 出典情報を集め直すスクリプト
- `drill/chusei.html` … 中世の巻 一問一答ドリル（単体で動く試験対策用。252問）

## 学校アカウント保存版（GAS）

`gas/` の2ファイルをスプレッドシートのApps Scriptに置くと、学校アカウントごとに記録をスプレッドシートへ保存する版になる。ゲーム本体はこのリポジトリの `index.html` を読み込むので、ゲームの更新はGitHub側だけでよい。

## 箱庭

ホームの「箱庭」で、斜め見下ろし（横2：縦1）の書斎を飾れる。家具は時代別の栞と交換し、「もようがえ」で置く。手に入れた頁は額に入れて壁に掛けられる。

- 家具の一覧は `index.html` のデータ内 `"furniture"`（1件1行）。`k`=キー、`e`=時代（0古代・1中世・2近世）、`t`=floor/wall、`w`・`d`=マス数、`h`=高さ、`p`=栞の枚数、`x`=紙魚の説明
- 絵ができたら `IMG` に `"家具_キー"`（例：`"家具_A1": "img/furn_A1.png"`）を足すと、仮の箱の代わりに表示される
- 絵の大きさ（1マス＝横96・縦48）
  - 床の家具：幅 (w+d)×48、高さ (w+d)×24＋h。左右向きは1方向だけ描けばよい（反転はゲーム側で行う）
  - 壁の家具：左の壁に掛けた向きで、幅 w×48、高さ h＋w×24（右の壁では反転して使う）
